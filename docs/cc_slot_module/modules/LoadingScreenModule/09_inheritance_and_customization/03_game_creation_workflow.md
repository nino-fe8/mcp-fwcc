1. Create a scene named `LoadingScene.fire`.
2. Add `LoadingScreenModule` to `Canvas/LoadingScreen`.
3. Fill in `sceneName: "g9666L"`, `sdSceneName: "g9666L-sd"`.
4. Link the `cc.ProgressBar` and `cc.Label` components.
