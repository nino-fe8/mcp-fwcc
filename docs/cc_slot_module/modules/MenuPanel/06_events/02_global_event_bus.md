## 1. Global Events Emitted

| Event | Purpose |
| :--- | :--- |
| `TOGGLE_BGM` | Toggles BGM active state. |
| `TOGGLE_SFX` | Toggles SFX active state. |
| `OPEN_PAY_TABLE_PANEL` | Opens PayTablePanel. |
| `OPEN_INFO_PANEL` | Opens InfoPanel. |
| `OPEN_BET_HISTORY_PANEL`| Opens BetHistoryModule. |
| `CLOSE_MENU_PANEL` | Dismisses menu drawer. |
