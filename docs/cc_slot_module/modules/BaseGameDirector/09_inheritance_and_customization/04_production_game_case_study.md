## 1. Context & Architecture Overview

In **Red Cliff (`g9666L`)**, Free Game mode inherits from `BaseGameDirector` to run multi-step spin cycles featuring expanding wilds and multiplier collections.

---

## 2. Production Code Excerpt

```typescript
@ccclass
export default class FreeGameDirectorModule9666 extends BaseGameDirector {
    @property(cc.Node)
    freeGameBg: cc.Node = null;

    onExtendedLoad(): void {
        this.node["director"] = this;
        this.node["writer"] = this.getComponent(FreeGameWriterModule9666);
        this.init();
    }

    async runFreeGameSpin(data: any): Promise<void> {
        // Runs the action script queue generated by FreeGameWriterModule9666
        await this.runAction("FreeSpinResult", data);
    }
}
```

---

## 3. Key Takeaways
1. **Clean Separation of Concerns**: The director focuses purely on node visual transitions and action dispatching, while `FreeGameWriterModule9666` manages the script steps.
2. **Robust Recovery**: `ScriptExecutor` automatically handles errors and abort signals (`forceToExit`) during network interruptions.
