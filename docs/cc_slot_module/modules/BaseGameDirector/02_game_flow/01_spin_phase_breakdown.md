## 1. Action Script Sequence Pipeline

`BaseGameDirector` structures the spin cycle into discrete declarative action sequences:

| Action Step Name | Typical Commands Generated by Writer | Purpose & Subsystems Awaited |
| :--- | :--- | :--- |
| **`SpinStart`** | `DEDUCT_BET`, `START_REEL_SPIN`, `LOCK_INPUTS` | Deducts balance, initiates infinite spin loop, locks UI buttons. |
| **`SpinResult`** | `STOP_REEL_SPIN`, `SHOW_NEAR_WIN`, `PLAY_STOP_SOUNDS` | Ingests server matrix, slows reels column by column, plays stop sounds. |
| **`WinPresentation`**| `SHOW_PAYLINES`, `TRIGGER_WIN_EFFECT`, `ROLL_BALANCE` | Highlights win lines, triggers Big Win cutscenes, rolls win balance. |
| **`FeatureTransition`**| `OPEN_INTRO_DIALOG`, `SWITCH_MODE_BGM`, `SWITCH_GAME_MODE` | Transitions scene graph into Free Game or Bonus Game. |
| **`SpinEnd`** | `UNLOCK_INPUTS`, `AUTO_SPIN_CHECK` | Commits round, re-enables spin buttons or auto-spins next round. |
